# Giver — памятка для новых сессий

Игра для телефона (Android): восхождение на гору с крюком и паркуром. Жанр — как у кооперативных
«лазалок» (вдохновлено PEAK, немного RV There Yet?, паркур — как обби в Roblox), но **своя игра**: свой
мир, герой и правила — не копировать чужие игры (названия, персонажей, предметы, уровни). Пользователь
пишет по-русски, отвечать по-русски, просто, по шагам: он работает с телефона и присылает скриншоты.

## Что сейчас в игре (версия 0.3)

- Остров с горой из уступов и стен. **Руками на стены не залезть** (так попросил пользователь) —
  вверх только: крюком в кольцо, по башне из досок, на грибе-батуте, на лифте.
- Крюк: прицел сам выбирает кольцо по направлению камеры (или ближайшее в 16 м), кнопка «Крюк» светится.
  Верёвка сама подтягивает (9 м/с), можно раскачиваться; у кольца герой перелезает на уступ. Ещё раз
  «Крюк» — отпустить, «Прыжок» на верёвке — сорваться с разгоном.
- Паркур: башня-обби (площадки по спирали, одна качается, наверху мостик), батут, лифт, звёзды (23).
- Лагеря (3) — точки сохранения, ягоды — силы. Вершина — ровная площадка с флагом.
- Новая графика (мягкий мультяшный стиль, как просил пользователь), новый интерфейс, качество
  «Низкая/Средняя/Высокая» (сохраняется; при тормозах игра сама понижает на ступень).

## Нагрев телефона (0.3) — пользователь жаловался, что телефон сильно греется

- По умолчанию «Низкая» (ключ сохранения `quality2`, старый `quality` из 0.2 игнорируется).
- Не больше 30 кадров/с на низкой и средней, 60 на высокой, 15 в меню/паузе (`frame()` в main.js) —
  без этого телефоны с экраном 90–120 Гц рисуют в 2–4 раза больше кадров.
- Эффекты postprocessing (свечение, AO, SMAA) — только на «Высокой». Тени: «Средняя» и «Высокая»,
  пересчёт не каждый кадр (`shadowMap.autoUpdate = false`, когда «солнце» сдвинулось и раз в 4 кадра);
  герой тень не отбрасывает — под ним свой кружок.
- Гора: 3 варианта шейдера (`terrainMaterial(0|1|2)`: без текстур / текстуры цвета / + неровности).
- Вода: наклон волн формулой (было 20 синусов на пиксель, стало 5). Без `backdrop-filter` в интерфейсе.
- Замер (SwiftShader, экран 915×412 ×2.6): было «Средняя» 0.2 — 706 мс/кадр, стало «Низкая» — 148,
  «Средняя» — 368. С учётом 30 кадров/с работы в секунду в 10–20 раз меньше.

## Где что лежит

```
src/
  main.js       сборка мира, игровой цикл (физика 60 шагов/с), камера, экраны, качество, сохранение
  gfx.js        рендер, небо, дымка, солнце с тенями (следует за героем), вода, шейдер горы, эффекты, QUALITY
  terrain.js    гора: сетка высот 257×257 (клетка 1.5 м), heightAt/normalAt, flatten, MOUNT (центр горы)
  course.js     МАРШРУТ: находит стены (findBand), ставит препятствия, звёзды, лагеря, подсказки; доски-коллайдеры
  world.js      природа (Kenney, инстансинг), кусты с ягодами, флаг, коллайдеры стволов/камней
  player.js     герой: земля/воздух/скольжение/верёвка/перелезание, крюк, доски, батут, анимация
  hero.js       модель героя (своя): круглая голова, шапка, шарф, рюкзак
  models.js     загрузка GLB из base64 (без fetch), PALETTE (перекраска Kenney), instance()
  fire.js       костёр и светлячки частицами
  input.js      джойстик слева, камера пальцем справа, кнопки крюк/прыжок/бег; ПК: WASD, Shift, пробел, E/ПКМ
  hud.js        полоски, полоска высоты с лагерями, звёзды, прицел крюка, сообщения
  assets.gen.js создаётся build.mjs (модели/текстуры/шрифты в base64) — в git не кладётся
assets/         models/*.glb (Kenney, CC0), textures/*.jpg (Poly Haven, CC0), fonts/*.woff2 (OFL), CREDITS.md
web/index.html  разметка, стили, SVG-иконки; <!--GAME--> заменяется на скрипт при сборке
build.mjs       → android/app/src/main/assets/web/{index.html,game.js}, dist/giver.html, dist/giver-artifact.html
android/        WebView-оболочка на весь экран, альбомная ориентация
experiments/    пробы графики (graphics2, camp-demo) — в игру уже перенесены, оставлены для истории
```

- Сборка: `npm ci && npm run build`. Всё (модели, текстуры, шрифты) внутри game.js — работает офлайн.
- Страница в APK: `file:///android_asset/web/index.html` — не менять (сохранение привязано к адресу).
  Скрипт обычный (не модуль). Мост: `window.AndroidBridge.exit()`, `window.__onBack()`.
- Сохранение: localStorage `giver_v1` = `{ best, bestStars, quality2 }`.
- Эффекты (postprocessing): на экран рисует ПОСЛЕДНИЙ добавленный слой — лишние слои убирать
  (`configureComposer`), а не выключать `enabled=false`, иначе чёрный/пустой экран.

## Как устроен маршрут (course.js)

- Полярные координаты от центра горы `MOUNT` (не от вершины!). `plan()` идёт от берега к центру и
  ищет стены выше 2.5 м (`findBand`), азимут каждой стены чуть сдвигается (ZIG) — тропа петляет.
- Вид препятствия: `PATTERN` + `chooseKind` (батут — если уступ перед стеной ≥ 2.4 м, башня — если стена
  ≤ 15 м, лифт ≤ 18 м, иначе крюк) + минимум 2 батута.
- Кольцо крюка висит на перекладине в 1.7 м над обрывом — чтобы было видно от самого низа стены.
- Башня: 6 площадок на виток (над площадкой следующий виток ≥ 3.3 м — иначе голова бьётся в прыжке),
  первая и последняя — со стороны стены, высота первой — от реальной земли под ней.
- Батут: вверх строго вертикально, над краем — скорость к уступу рассчитывается, чтобы долететь.
- `course.route` — шаги для бота (walk / hook / stairs / bounce / lift).

## Сборка APK

- APK собирает GitHub Actions при push в `main` (кроме правок только `*.md` и `experiments/**`) и
  вручную (`actions_run_trigger` → `run_workflow`, `build-apk.yml`). Кладёт `Giver.apk` в релиз `latest`.
- Скачать `https://github.com/zlontp98-bit/Giver/releases/download/latest/Giver.apk` через curl, сверить
  sha256 с digest релиза и отправить файлом (SendUserFile).
- Перед сборкой поднимать `versionCode`/`versionName` в `android/app/build.gradle` (сейчас 3 / 0.3).
  Подпись — `android/app/debug.keystore` (пароль android), ставится поверх.

## Как проверять

- Chromium через Playwright, `args: ['--enable-unsafe-swiftshader', '--use-angle=swiftshader']`.
  Скриншоты — с `deviceScaleFactor: 1` или 2 и `timeout` побольше; `window.__noAdapt = true` — чтобы
  игра не понижала качество (в SwiftShader всё «тормозит»).
- `window.__giver` = `{ game, player, terrain, course, world, cam, input, gfx, setQuality, step(inp) }`.
  `step()` — один шаг физики без рисования. Бот проходит маршрут по `course.route` (крюк: `player.pickTarget(dir)`
  и `input.hook`; доски: разбег, прыжок, торможение в воздухе). Последний прогон: вершина за ~2.5 мин
  игрового времени, 23/23 звезды, без падений.
- Касания — pointer-события (`pointerType: 'touch'`) на `#layer` и кнопках `#bHook`, `#bJump`, `#bRun`.

## Планы (обсудить с пользователем)

Игра с друзьями по сети; звуки и музыка; больше видов паркура (качели на крюке через пропасть,
исчезающие платформы, ветер); еда/снаряжение; каждый день новая гора (зерно = дата); поездка до
подножия на машине (RV There Yet). Модель телефона пользователь не назвал — производительность на
телефоне не проверена.
