# Giver — памятка для новых сессий

Игра для телефона (Android): восхождение на гору. Жанр — как у кооперативных «лазалок» (вдохновлено
PEAK, немного RV There Yet?), но **своя игра**: свой мир, свои правила — не копировать чужие игры
(названия, персонажей, предметы, уровни). Пользователь пишет по-русски, отвечать по-русски, просто,
по шагам: он работает с телефона и присылает скриншоты.

## Где что лежит

```
src/            код игры (ES-модули)
  main.js       сцена, камера, игровой цикл, экраны (старт/пауза/падение/вершина), рекорд
  terrain.js    остров с горой: сетка высот 257×257 (клетка 1.5 м), рисование, heightAt/normalAt
  world.js      море, ёлки, камни, кусты с ягодами, лагеря (точки сохранения), флаг на вершине
  player.js     герой: ходьба/бег/прыжок, скольжение, лазание по скалам, силы (stamina), здоровье
  input.js      джойстик слева, камера пальцем справа, кнопки «прыжок/хват/бег»; WASD/мышь на ПК
  hud.js        полоски, высота, время, сообщения
  noise.js      случайные числа с зерном и шум
web/index.html  разметка и стили; <!--GAME--> заменяется на скрипт при сборке
build.mjs       сборка esbuild → android/app/src/main/assets/web/{index.html,game.js} и dist/giver.html
android/        Android-оболочка: WebView на весь экран, альбомная ориентация
.github/workflows/build-apk.yml   сборка APK в GitHub Actions
```

- Сборка: `npm ci && npm run build` (three.js 0.170 и esbuild из npm). Собранное в git не кладётся
  (`.gitignore`), Actions собирает само.
- `dist/giver.html` — вся игра одним файлом: открыть в браузере / выложить артефактом на claude.ai.
  Артефакт «Giver — восхождение» (https://claude.ai/artifact/KpySPZDkWR8mYzkeUpVUZw,
  slug 98773beb-858d-4f38-ba6f-c0d3bdcda632) — в него играют прямо в приложении Claude; после
  изменений обновлять его (`publish_files` с `slug`/`base_version`; файл для публикации должен лежать
  в рабочей папке сессии — скопировать туда на время и потом удалить).
- Страница в APK грузится по адресу `file:///android_asset/web/index.html` — не менять (рекорд в
  localStorage привязан к адресу). Скрипт — обычный (не модуль), иначе file:// не пустит.
- Мост Android → JS: `window.AndroidBridge.exit()`; JS ← Android: `window.__onBack()` (кнопка «Назад»:
  пауза/продолжить; вернул false — приложение закрывается).
- Сохранение: localStorage `giver_v1` = `{ best }` (лучшее время).

## Как устроена гора и лазание

- Гора — «ступени»: пологая полка (можно стоять, силы восстанавливаются) и крутая стена ~75°.
  Всё круче `WALKABLE_NY` (нормаль.y < 0.72, ~44°) — стена: по ней только лезть.
- Лазание идёт по поверхности сетки высот (нормаль сглажена по соседям), герой «прилипает» к ней.
  Наверху стены, где снова пологое, — сам выходит на полку.
- Силы: лезть 6.5/с, висеть 2.5/с, бег 11/с, прыжок 8, рывок на скале 18, поймать скалу в полёте 6;
  восстановление 15/с через 0.7 с без трат. Падение выше 6 м — урон.
- Зерно горы — `SEED` в main.js (одно зерно = одна и та же гора).

## Сборка APK

- В этой среде Android SDK нет — APK собирает GitHub Actions: при каждом push в `main` и вручную
  (`actions_run_trigger` → `run_workflow`, `build-apk.yml`). Кладёт `Giver.apk` в релиз `latest`.
- Пользователь не может скачать APK по ссылке GitHub — скачать
  `https://github.com/zlontp98-bit/Giver/releases/download/latest/Giver.apk` через curl и отправить
  файлом (SendUserFile). Сверить sha256 с digest релиза.
- Перед новой сборкой поднимать `versionCode`/`versionName` в `android/app/build.gradle`
  (сейчас 1 / 0.1). Подпись — `android/app/debug.keystore` (пароль android), ставится поверх.
- MainActivity проверять `javac` против `org.robolectric:android-all:13-robolectric-9030017` (Maven Central).

## Как проверять

- Chromium через Playwright (`require('playwright')`), запуск с
  `args: ['--enable-unsafe-swiftshader', '--use-angle=swiftshader']` — WebGL работает, но медленно.
- `window.__giver` — доступ к игре: `{ game, player, terrain, world, cam, input, step(inp) }`.
  `step()` двигает физику на 1/60 с без рисования — так бот быстро проверяет, что гора проходима
  (поставить `game.running = false`, крутить `step` в цикле, камеру — `cam.yaw`).
- Касания проверять pointer-событиями (`pointerType: 'touch'`) на `#layer` и кнопках.

Пользователю нравится мягкий мультяшный вид, как в PEAK (присылал скриншот): гладкие склоны, тёплые
цвета, дымка вдали, тени. Сделана проба — `experiments/graphics2/` (`node experiments/graphics2/build.mjs`

  оранжевая шапка с помпоном, бирюзовая куртка, красный шарф и варежки, рюкзак со спальником.
- `demo.js` — та же гора (`Terrain`), но: гладкие нормали, шейдер рельефа (слоистый песчаник на стенах,
  серый камень и снег выше, пятна травы, пена у воды), небо-градиент с солнцем (без тонировки, иначе
  горизонт темнее дымки), `FogExp2`, тени PCFSoft вокруг героя, ACES-тонировка, пальмы, круглые
  деревья, ёлки, валуны.

## Пример «Вечерний лагерь» (новые возможности, в игру ещё не перенесён)

`experiments/camp-demo/` — лагерь у костра на уступе: модели Kenney Nature Kit (перекрашены, `PALETTE`),
текстуры Poly Haven (скалы — трипланарная проекция цвета и нормалей), костёр и светлячки частицами
(`fire.js`), вода-шейдер с бликами, эффекты postprocessing (bloom, ACES, виньетка, SMAA) + N8AO;
на слабом телефоне сам снижает качество. GLB разбираются из base64 без fetch (в артефакте fetch data: может
быть запрещён). Сборка: `node experiments/camp-demo/build.mjs` (из корня; `absWorkingDir` обязателен —
иначе esbuild соберёт игру из корневого src/). Артефакт: https://claude.ai/artifact/W9Nq2FqUtMEqtoVuEn9Vs4
(обновлять публикацией файла `experiments/camp-demo/artifact/camp.html` с `url`). Источники — CREDITS.md.

## Что доступно для графики (проверено)

- npm открыт: `postprocessing` (свечение, цвет), `n8ao` (мягкие тени в щелях), `three.quarks` (частицы),
  `@dimforge/rapier3d-compat` (физика: верёвки, «кукла» при падении), `three-custom-shader-material`,
  `@pmndrs/assets` (CC0: HDRI неба, карты нормалей, matcap). PyPI открыт: `bpy` 5.2.3 (Blender как
  модуль Python 3.13) — не ставили.
- Сеть: пользователь открыл доступ (Custom/Full) — kenney.nl, quaternius.com, polyhaven.com
  (api.polyhaven.com, dl.polyhaven.org), ambientcg.com, huggingface.co работают. Kenney отдаёт zip через
  `https://kenney.nl/download-link/<id>` (id — `data-download-id` на странице набора, нужен User-Agent).
- Hugging Face подключён (аккаунт Abobus2000): поиск работает, а рисование (dynamic_space invoke)
  выключено (`gradio=none`) — пользователю объяснено, как включить Spaces на huggingface.co/settings/mcp.
- Своих рисунков-нейросетей у Claude нет. Предложено пользователю: подключить коннектор Hugging Face
  (claude.ai/customize/connectors, потом новая сессия) — через него Gradio-приложения (картинки, 3D);
  или самому делать модели в Meshy/Tripo (.glb) и картинки в любых рисовалках и присылать.
