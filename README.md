# Giver — восхождение с крюком

Игра для телефона: остров, наверху горы — флаг. Руками на скалы не залезть — только крюком,
прыжками по башням из досок, на грибах-батутах и лифтах.

- Левая половина экрана — идти (дотянешь палец далеко или нажмёшь «»» — бег), правая — камера.
- **Крюк**: наведи камеру на светящееся кольцо и нажми — подтянет наверх. Ещё раз — отпустить.
- **Прыжок**: по доскам и платформам; на верёвке — сорваться с разгоном.
- Звёзды — собирать, палатки — точки сохранения, ягоды — силы.
- Графика: Низкая / Средняя / Высокая (в меню и в паузе).

APK собирается автоматически (GitHub Actions) и лежит в релизе **latest**.

Для разработчика: `npm ci && npm run build`, затем открыть `dist/giver.html` в браузере
(на компьютере: WASD, Shift — бег, пробел — прыжок, E или правая кнопка мыши — крюк, мышь — камера).
Модели — Kenney (CC0), текстуры — Poly Haven (CC0), шрифты — Comfortaa и Nunito (OFL): см. `assets/CREDITS.md`.
