# Giver — спуск в Бездну

Игра для телефона: посреди леса — Бездна глубиной 232 метра. Спустись на самое дно, к огромному
светящемуся кристаллу. Четыре яруса: Устье, Корневой ярус, Хрустальные гроты и Дно — чем глубже,
тем темнее и тем ярче светятся кристаллы.

- Левая половина экрана — идти (дотянешь палец далеко или нажмёшь «»» — бег), правая — камера.
- **Хват** у стены — повиснуть на руках. Джойстик — лезть вниз, вверх и вбок. Силы тают — отдыхай на уступах.
  Можно схватиться за стену, даже когда падаешь.
- **Крюк**: у светящегося кольца — спуск по верёвке (джойстик вниз), у троса — прокатиться через бездну.
- **Прыжок**: по парящим камням; огромный гриб смягчит падение. Падать высоко — больно.
- Осколки — собирать, палатки — точки сохранения, ягоды — силы.
- Графика: Низкая / Средняя / Высокая (в меню и в паузе). Если телефон греется — «Низкая».

APK собирается автоматически (GitHub Actions): рабочая версия «Giver» — в релизе **latest**,
тестовая «Giver Тест» (ветка `dev`, ставится рядом с рабочей) — в релизе **test**.
В паузе можно включить счётчик FPS и сделать «Замер скорости» (30 секунд) — пришли скриншот итога.

Для разработчика: `npm ci && npm run build`, затем открыть `dist/giver.html` в браузере
(на компьютере: WASD, Shift — бег, пробел — прыжок, Q — хват, E или правая кнопка мыши — крюк, мышь — камера).
Проверки: `node tools/bot.cjs` (бот проходит всю Бездну), `node tools/flows.cjs`, `node tools/bench.cjs`, `node tools/perf.cjs low`.
Модели — Kenney (CC0), текстуры — Poly Haven (CC0), шрифты — Comfortaa и Nunito (OFL): см. `assets/CREDITS.md`.
