# Giver — восхождение

Игра для телефона: ты на берегу острова, наверху горы — флаг. Доберись до вершины!

- Левая половина экрана — водишь пальцем, герой идёт (дотянешь далеко или нажмёшь «»» — бежит).
- Правая половина — поворот камеры.
- ✋ «Хват» у скалы — ухватиться и лезть, ещё раз — отпустить. Можно поймать скалу в падении.
- ⤒ «Прыжок»; на скале — рывок вверх.
- Лезть, бегать и прыгать тратит силы. Кончатся на скале — сорвёшься. Отдыхай на уступах.
- Ягоды возвращают силы, лагеря с палатками — точки сохранения.

APK собирается автоматически (GitHub Actions) и лежит в релизе **latest**.

Для разработчика: `npm ci && npm run build`, затем открыть `dist/giver.html` в браузере
(на компьютере: WASD, Shift — бег, пробел — прыжок, E — хват, мышь — камера).
